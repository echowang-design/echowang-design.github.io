# Echo Wang Portfolio — V0.2

GitHub Pages-ready static portfolio prototype.

## What changed in V0.2
- Replaced click-to-teleport map navigation with a lightweight side-scrolling platformer-style world.
- Arrow keys / A-D move the avatar; Space jumps; E opens the nearby section.
- Added HOME and WORLD navigation.
- CLOSE now closes the portfolio panel and returns to the world.
- ESC closes an open panel/menu.
- Reworked the palette to neutral black / white / grey with a small blue accent.
- Added temporary web image placeholders only for testing composition. Replace them with Echo's real work later.
- Added basic mobile controls.

## Files
- `index.html` — page structure
- `style.css` — visual system and platformer scene
- `script.js` — movement, camera, navigation and panels
- `assets/` — reserved for real portfolio images later

## Controls
- `←` / `→` or `A` / `D`: move
- `Space`: jump
- `E`: enter the nearby portfolio area
- `ESC`: close panel/menu
