# Echo Wang Portfolio — V0.1

这是第一版可直接部署到 GitHub Pages 的静态网站。

文件：
- index.html：网页主体
- style.css：视觉样式
- script.js：交互逻辑
- assets/：以后放作品图片、头像、项目素材

当前版本包含：首页、自我介绍、ENTER MY WORLD、作品集地图、5个可点击区域、人物移动、内容面板、MENU快速导航、手机端基础适配，以及 Tokyo Ghoul / Yu Yu Hakusho / LAB 等占位内容。

人物目前使用 CSS 占位图。下一步先部署成功，再替换真实人物、作品封面、项目过程图和完整案例。
